分割参数（可实时微调）

算法与 Python 版一致：ExG = 2g - r - b（色度归一化）→ Otsu 自动阈值 → HSV 绿色区间 → 形态学清理 → 连通域统计。 黄叶单独放宽颜色阈值，但只接纳与绿色主体相接的整片黄叶，避免把土块和枯枝误检成植物。 已知局限：贴在一起的植株会被算作一个区域。想看命令行版本请回到 python -m plantdet -i 图片。
